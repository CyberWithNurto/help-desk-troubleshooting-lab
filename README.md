# help-desk-troubleshooting-lab
Hands-on IT help desk and technical support lab featuring Windows, Linux, networking, DNS, browser troubleshooting, ticket documentation, and SaaS support simulations.
This repository contains my hands-on technical support and help desk labs as I build real-world troubleshooting skills for remote IT support, SaaS support, and cloud support roles.

The goal of this lab is to simulate real-world technical support scenarios using Windows, Linux, networking tools, browser troubleshooting, and ticket documentation.

Skills practiced include:
- Windows troubleshooting
- Linux support basics
- Networking and DNS troubleshooting
- Browser and SaaS troubleshooting
- Ticket documentation
- Command-line tools
- Virtual machine labs
- Customer support simulations
