
1. IP Address
   
Stands for: Internet Protocol Address
What it is: A number that identifies a device on a network.
Why it is used: Devices need addresses so they can send data to the right place.
Real job example: A user says, “My internet is not working.” You check if their device has a valid IP address.

Short Summary: 
IP address = device’s address on a network.
Example: 192.168.1.15
If there is no valid IP, the device may not connect to the network.

How Look up IP Address on Commonds:
Windows command: ipconfig
Linux command: ip addr
