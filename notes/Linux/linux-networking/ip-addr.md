# ip addr

## Screenshot
![ip-addr](../../../screenshots/Linux/networking/ip-addr.png)

## Command Used

```bash
ip addr
```

## What It Does
Displays Linux network interface and IP address information.

## Why It Is Used
Support technicians use this command to verify:
- IP addresses
- network interfaces
- connectivity settings

## Real Job Example
A Linux system cannot connect to the internet.
A technician checks whether the system received a valid IP address.

## Difference Between Windows and Linux
Windows commonly uses:
```cmd
ipconfig
```

Linux commonly uses:
```bash
ip addr
```

Both commands display network configuration information, but Linux uses different networking utilities.

## My Result
My Kali Linux VM successfully displayed a valid IP address and active network interface.
