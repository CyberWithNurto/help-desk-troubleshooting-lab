# ip a

## Command
```bash
ip a
```

## What It Does
Displays network interface and IP address information on Linux systems.

## Why IT Support Uses It
IT technicians use this command to:
- Identify IP addresses
- Check network interfaces
- Troubleshoot connectivity issues
- Verify network adapter status

## What I Learned
I learned how Linux displays:
- Network interfaces
- IPv4 addresses
- MAC addresses
- Interface states

I also noticed Linux networking commands are different from Windows commands like ipconfig.
