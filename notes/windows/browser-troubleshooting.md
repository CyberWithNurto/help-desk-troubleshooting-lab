# Windows Browser Troubleshooting

## Overview
This document contains notes and practice related to browser and SaaS troubleshooting on Windows.

## Topics Covered
- Browser troubleshooting
- Chrome DevTools
- HTTP status codes
- Cache and cookies
- SaaS troubleshooting
- Browser extensions

## Tools Used
- Google Chrome
- Chrome DevTools

## HTTP Status Codes

### 200
Successful request.

### 401
Authentication issue or login problem.

### 403
User authenticated but lacks permission.

### 404
Page or resource not found.

### 500
Internal server error.

### 503
Service unavailable.

## Troubleshooting Steps
1. Verify the issue.
2. Test incognito mode.
3. Clear cache and cookies.
4. Disable browser extensions.
5. Open DevTools Console.
6. Check Network tab.
7. Review HTTP status codes.

## Real Job Example
A user cannot access a SaaS dashboard. A support technician checks browser cache, DevTools errors, and user permissions.
