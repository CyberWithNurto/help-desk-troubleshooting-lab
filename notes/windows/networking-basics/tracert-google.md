# tracert google.com

## Screenshot
![tracert-google](../../../screenshots/windows%20/networking-basics/tracert-google.png)

## Command Used

```cmd
tracert google.com
```

## What It Does
Displays the network path taken to reach a destination server.

## Why It Is Used
Support technicians use tracert to identify:
- slow network routes
- connection failures
- routing problems
- latency issues

## Real Job Example
A remote employee reports slow access to a company application.
A technician uses `tracert` to identify where delays occur along the network route.

## My Results
The trace successfully reached Google's server after multiple network hops without failures or timeouts.

## What I Learned
I learned how network traffic travels between systems and how support technicians use tracert to diagnose routing and connectivity issues.
