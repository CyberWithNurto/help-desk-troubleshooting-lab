# nslookup google.com

## Screenshot
![nslookup-google](screenshots/windows%20/networking-basics/nslookup-google.png)

## Command Used

```cmd
nslookup google.com
```

## What It Does
Queries DNS servers to translate domain names into IP addresses.

## Why It Is Used
Support technicians use nslookup to troubleshoot:
- DNS issues
- website resolution problems
- connectivity issues
- incorrect DNS settings

## Real Job Example
A user can access websites using IP addresses but cannot access websites using domain names.
A technician uses `nslookup` to verify whether DNS is working properly.

## My Results
The DNS server successfully translated `google.com` into IPv4 and IPv6 addresses.

## What I Learned
I learned how DNS converts domain names into IP addresses and how support technicians verify DNS functionality during troubleshooting.
