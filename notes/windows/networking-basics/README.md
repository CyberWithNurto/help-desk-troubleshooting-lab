# Windows Networking Basics

This folder contains notes and hands-on practice related to Windows networking and connectivity troubleshooting.

## Topics Covered
- IP addresses
- DNS
- DHCP
- Default gateway
- Ping
- Nslookup
- Tracert
- Connectivity troubleshooting

## Skills Practiced
- Network diagnostics
- DNS troubleshooting
- Connectivity testing
- Windows command-line networking tools
- Technical documentation

## Commands Practiced
```cmd
ipconfig /all
ping google.com
nslookup google.com
tracert google.com
```

## Goal
The goal of this section is to build foundational networking and troubleshooting skills used in technical support and SaaS support roles.
