# ping google.com

## Screenshot
![ping-google](../../../screenshots/windows%20/networking-basics/ping-google.png)

## Command Used

```cmd
ping google.com
```

## What It Does
Tests whether the system can communicate with another server over the network.

## Why It Is Used
Support technicians use ping to test:
- internet connectivity
- DNS functionality
- network response
- packet communication

## Real Job Example
A user reports that websites are not loading properly.
A support technician uses `ping google.com` to verify whether the device can communicate with external servers.

## What I Learned
I learned how to test basic network connectivity and verify whether a system can communicate with external websites.
