# ipconfig /all

## Screenshot
![ipconfig-all](../../../screenshots/windows/networking/ipconfig-all.png) 

## Command Used

```cmd
ipconfig /all
```

## What It Does
Displays detailed network configuration information for a Windows device.

## Why It Is Used
Support technicians use this command to verify:
- IP address
- subnet mask
- default gateway
- DNS servers
- DHCP information

## Real Job Example
A user reports they cannot access the internet.
A technician uses `ipconfig /all` to verify whether the device received a valid network configuration.

## What I Learned
I learned how to identify important Windows network configuration settings and verify basic connectivity information.
